# Bestiary — setup guide

Your personal monster library. Runs in Chrome, installs to your home screen, and works fully offline once installed.

## One-time setup: put it online with GitHub Pages (about 15 minutes)

The app needs to be loaded from a web address once so Chrome can install it. GitHub Pages hosts it free.

1. Make a free account at github.com (skip if you have one).
2. Click **+** (top right) → **New repository**. Name it `bestiary`, set it to **Public**, tick **Add a README file**, and click **Create repository**.
3. On your PC, unzip `bestiary.zip`.
4. In the new repository, click **Add file** → **Upload files**. Drag in everything from inside the unzipped folder (the files *and* the `fonts` and `icons` folders). Click **Commit changes**.
5. Go to **Settings** → **Pages**. Under "Branch," pick `main` and `/ (root)`, then **Save**.
6. Wait a minute or two. The page shows your address, something like `https://yourname.github.io/bestiary/`.

## Install on the Tab S9+

1. Open that address in **Chrome** on the tablet.
2. Tap the **⋮** menu → **Add to home screen** → **Install**.
3. Open it from the home screen icon once while still online. From then on it works with Wi-Fi off.

Do the same on your PC in Chrome (install icon in the address bar) if you want a desktop copy for heavy entry.

## Moving work between PC and tablet

Settings (gear icon) → **Save backup file** on one device, put the file in Google Drive, then **Load backup file** on the other. Loading merges: new monsters are added, and when a monster exists on both, the most recently edited version wins.

Save a backup now and then even if you only use the tablet. Everything lives on the device, so the backup file is your safety net.

## Updating the app later

When I send you new files, upload them to the same repository the same way (replace the old ones). The next time the app opens while online, it picks up the update. Your monsters are not touched by updates.
